# Politique de sécurité (Security Policy)

## Versions supportées

Nous fournissons des mises à jour de sécurité pour la version la plus récente de l'installateur.
Veuillez toujours utiliser la dernière version disponible dans la section Releases.

| Version              | Supportée          |
| -------------------- | ------------------ |
| Dernière (Latest)    | :white_check_mark: |
| Versions précédentes | :x:                |

## Signaler une vulnérabilité

Si vous découvrez une faille de sécurité dans cet installateur ou dans les scripts qu'il contient,
**merci de ne pas ouvrir d'Issue publique**.

Veuillez contacter le mainteneur du projet directement :

- Par e-mail : timeobonnin@outlook.fr

Nous nous engageons à examiner chaque signalement et à publier un correctif dans les plus brefs délais.
Merci de contribuer à la sécurité de ce projet !
