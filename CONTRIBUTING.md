# Guide de contribution

Merci de votre intérêt pour ce projet. Voici comment vous pouvez contribuer.

## Signaler un bug

Avant de créer un rapport de bug, vérifiez si le problème n'a pas déjà été signalé dans les **Issues**. Si ce n'est pas le cas, ouvrez une nouvelle issue en incluant :

- Un titre clair et descriptif.
- Les étapes exactes pour reproduire le bug.
- Le comportement attendu et le comportement observé.

## Proposer une amélioration

Les suggestions sont les bienvenues. Ouvrez une **Issue** avec l'étiquette `enhancement` pour expliquer votre idée et son utilité pour le projet.

## Soumettre une modification (Pull Request)

1. **Forkez** le dépôt sur votre compte.
2. **Clonez** votre fork sur votre machine locale.
3. Créez une nouvelle branche pour votre modification (`git checkout -b feature/ma-fonctionnalite`).
4. Faites vos modifications et testez-les.
5. Commitez vos changements avec un message clair (`git commit -m "Ajout de ma fonctionnalité"`).
6. Poussez votre branche vers votre fork (`git push origin feature/ma-fonctionnalite`).
7. Ouvrez une **Pull Request** vers la branche principale de ce dépôt.

## Règles de base

- Ajoutez des tests si vous introduisez une nouvelle fonctionnalité.
- Soyez respectueux et constructif dans tous les échanges.
